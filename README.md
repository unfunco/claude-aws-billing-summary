#### Monthly summary

The following report is generated by the
[.github/workflows/generate-monthly-summary.yaml] workflow, it is scheduled to
run at the start of every month to generate a brief summary of the previous
month's AWS costs compared to the month before.

>
> Your total AWS bill decreased by $12.76 (31%) from $41.16 in June to $28.40 in
> July.
>
> **Key changes:**
>
> - AWS Key Management Service dropped 43% ($10.28 decrease)
> - AWS WAF fell 51% ($3.05 decrease)
> - AWS Config appeared as a new service costing $2.19
> - CloudTrail started billing $0.22
> - S3 costs increased 68% but only $0.29 in absolute terms
> - Route 53 remained steady at $3.52
>
> The substantial KMS reduction drove most of your savings. Apparently you
> either
> finished a heavy encryption project or discovered the bills were getting
> painful.
